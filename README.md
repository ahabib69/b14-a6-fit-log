# FitLog

Dark workout tracker built for Programming Hero Assignment 6.

Browse workouts, build today's plan (max 5), save some for later, mark them done. Data stays in localStorage so it survives refresh.

## Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Context API + localStorage

## Features
- 12 workouts from the API
- Sort by duration, calories or rating
- Detail page for every workout
- Add to today's plan or save for later
- Plan page with live counters, tabs, done & remove
- Toast feedback
- Mobile friendly

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

No env vars needed.
