# FitLog

A dark, responsive Workout Library and Workout Planning website built for Programming Hero Assignment 6.

Browse workout data from the API, open dynamic workout details, add lifts to Today's Plan, save workouts for later, mark planned workouts as done, and keep plan data after refresh with localStorage.

## Technologies

- Next.js (App Router)
- React
- Tailwind CSS
- Context API
- localStorage
- Fetch API

## Key Features

- 12 workouts loaded from the FitLog API
- Responsive workout library with search and sorting by duration, calories, or rating
- Dynamic workout details pages with instructions and workout specs
- Today's Plan with a maximum of 5 workouts
- Saved workouts with live navbar counters
- Mark as Done, remove, toast notifications, and localStorage persistence
- Responsive layout for mobile, tablet, and desktop
- Custom 404 and loading states

## Run Locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

No environment variables are required.
